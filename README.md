# 🤖 AI Task Manager - Персональный помощник для управления задачами

Telegram бот с AI агентом для умного управления задачами, целями и планированием.

## ✨ Возможности

### 🎯 Основные функции
- **Умное создание задач** - просто напишите что нужно сделать, AI распарсит дату, время и приоритет
- **Управление целями** - создавайте долгосрочные цели, AI предложит подзадачи
- **Календарь** - планирование задач по дням
- **AI агент** - персональный помощник, которого можно настроить под себя
- **Напоминания** - уведомления о важных задачах (в разработке)
- **Аналитика** - советы по продуктивности (в разработке)

### 🤖 AI возможности
- Автоматический парсинг задач из естественного языка
- Определение приоритета и сроков
- Разбиение целей на подзадачи
- Ежедневные мотивирующие сводки
- Настраиваемый промпт агента

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Установка Python пакетов
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```env
# 1. Telegram Bot Token (обязательно)
TELEGRAM_BOT_TOKEN=your_token_here

# 2. AI API Key (выберите один вариант)
GROQ_API_KEY=your_groq_key_here  # РЕКОМЕНДУЮ
# или
OPENROUTER_API_KEY=your_key_here
# или
ANTHROPIC_API_KEY=your_key_here

# 3. Настройки AI
AI_PROVIDER=groq  # groq, openrouter, anthropic
AI_MODEL=llama-3.3-70b-versatile
```

### 3. Получение API ключей

#### Telegram Bot Token (обязательно)
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

#### AI API Key (выберите один)

**Вариант 1: Groq (РЕКОМЕНДУЮ - быстро и бесплатно)**
1. Зайдите на [groq.com](https://console.groq.com)
2. Зарегистрируйтесь
3. Создайте API ключ в разделе API Keys
4. **Бесплатно:** 14,400 запросов/день
5. **Скорость:** 300+ токенов/секунду

**Вариант 2: OpenRouter (много моделей бесплатно)**
1. Зайдите на [openrouter.ai](https://openrouter.ai)
2. Зарегистрируйтесь
3. Получите ключ в Settings → API Keys
4. **Бесплатно:** доступ к 30+ моделям

**Вариант 3: Anthropic Claude (качественно, но платно)**
1. Зайдите на [console.anthropic.com](https://console.anthropic.com)
2. Получите API ключ
3. **Стоимость:** ~$0.25 за 1M токенов (Claude Haiku)

### 4. Инициализация базы данных

```bash
python database.py
```

Вы увидите: `✅ База данных инициализирована`

### 5. Запуск бота

```bash
python telegram_bot.py
```

Вы увидите: `✅ Бот работает. Нажмите Ctrl+C для остановки.`

## 📱 Использование

### Базовые команды

```
/start - Начало работы
/help - Справка
/tasks - Список задач
/goals - Список целей
/today - План на сегодня
/agent - Настроить AI агента
```

### Создание задач

Просто напишите боту что нужно сделать:

```
Купить молоко завтра в 10:00
→ AI создаст задачу на завтра 10:00, средний приоритет

Закончить отчёт к пятнице, это срочно!
→ AI создаст задачу на пятницу, высокий приоритет

Позвонить маме когда-нибудь
→ AI создаст задачу без даты, низкий приоритет
```

### Работа с целями

1. Создайте цель через `/goals`
2. AI предложит разбить её на подзадачи
3. Отслеживайте прогресс

### Настройка AI агента

```
/agent → Изменить имя/промпт
```

Примеры кастомных промптов:
- "Ты строгий тренер по продуктивности"
- "Ты дружелюбный помощник, который поддерживает"
- "Ты эксперт по тайм-менеджменту"

## 🗄️ База данных

SQLite база с тремя таблицами:

### Users (Пользователи)
- `telegram_id` - ID в Telegram
- `agent_name` - Имя AI агента
- `agent_prompt` - Промпт агента

### Tasks (Задачи)
- `title` - Название
- `description` - Описание
- `scheduled_date` - Дата и время
- `priority` - Приоритет (low/medium/high)
- `completed` - Завершена?

### Goals (Цели)
- `title` - Название
- `description` - Описание
- `deadline` - Крайний срок
- `tasks` - Связанные задачи

## 🔧 Настройки

### Выбор AI провайдера

В `.env` измените:

```env
# Для Groq (быстро, бесплатно)
AI_PROVIDER=groq
AI_MODEL=llama-3.3-70b-versatile

# Для OpenRouter (много моделей)
AI_PROVIDER=openrouter
AI_MODEL=meta-llama/llama-3.1-8b-instruct:free

# Для Anthropic (качество)
AI_PROVIDER=anthropic
AI_MODEL=claude-haiku-4-20250514
```

### Смена часового пояса

```env
TIMEZONE=Europe/Moscow  # или America/New_York, Asia/Tokyo и т.д.
```

## 🐛 Решение проблем

### Бот не отвечает
```bash
# Проверьте токен
echo $TELEGRAM_BOT_TOKEN

# Проверьте логи
python telegram_bot.py
```

### AI не работает
```bash
# Проверьте API ключ
echo $GROQ_API_KEY

# Попробуйте другой провайдер
AI_PROVIDER=openrouter
```

### База данных
```bash
# Пересоздать базу
rm tasks.db
python database.py
```
